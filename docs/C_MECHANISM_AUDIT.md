# C 组性能差距与机制审计

**目标尚未完成：当前结果不能称为完整复现论文性能差距及其形成机制。** 实验运行、方程实现、参数相同、甚至 RMSE 排名相同，都不是充分的完成条件。最终数字和全部正式对照见 [结果报告](results/c-mechanism/REPORT.md)。本文件记录判据、来源和实现边界。

用户确认 FR3 控制与传感器均为 1000 Hz；用户没有作者代码、附带视频或原始实验数据。实机是否启用 100 Hz 命令滤波尚不确定，因此正式矩阵同时验证开关，不能根据某一分支效果好就推断实机配置。

## 判据

1. 轨迹、斜面及转角交互、法向力 `10+3 sin(t)`、Λ/D/K 与论文对齐。作者明确数值、图示恢复值、未标定假设分别记录。
2. 在共同环境和共同传感/执行接口下，普通导纳持续抖振，H∞ 稳定跟踪；双向调制稳定接触，但实现期望阻抗的精度下降。
3. 内部正功率、调制后的残余、反馈补偿力矩、虚拟状态、β、能量罐、限幅、接触状态可检查。β 的图示尖峰不能替代功率与因果证据。
4. 固定 β=0/1、去除摩擦和噪声的消融支持机制；固定 β 只是反事实实验，不能作为最终调制控制器。数值积分与采样不稳定必须和连续控制结构的机制分开。
5. 多种子、物理和虚拟积分细化后结论成立。明确披露失败条件和排名反转。
6. C 的论文 α=1 单独验证。α=0.25 或降低 NRIC G 属于 FR3 适配，不能冒充论文原增益。

## 论文与图示证据

主论文 DOI `10.1109/TRO.2026.3741518`：

- 第 11 页：Indy7 六轴、高减速比关节；关节摩擦明显，传感器/工具重量未加入名义模型。
- 第 12 页：控制 4 kHz、F/T 1 kHz；A–E 使用 α=1、γ=0.1、Kγ=(1000,1000,1000,50,50,50)。NRIC G=(1200,1200,600,400,400,400)，Kp=(60,60,40,30,30,30)，Ki=5。第七轴沿用最后一个腕部值是本项目扩展。原机内环带宽约 17/13/23/63/69/69 Hz；直接复制增益不保证 FR3 获得相同带宽。
- 第 15 页：C 的 Λ=(4,4,10,.4,.4,.4)，D=(80,80,200,80,80,80)，K=(400,400,0,400,400,400)；图 8 为有斜面和转角的挡块，图 9 为比较曲线，主要交互约 13–19 s。

PDF 保存了原生矢量折线。`scripts/digitize_paper_c.py` 通过 Poppler SVG 恢复曲线并校准坐标轴。恢复的目标力与 `10+3 sin(t)` 的 RMS 差约 0.003 N；轨迹分块边界的相位误差小于 0.0003 rad。这是绘图数据的恢复，**不是作者 1/4 kHz 原始日志**。

恢复的轨迹为：

```
x = x0 + 0.05 sin(pi*t/6)
y = y0 + 0.15 sin(pi*t/12)
```

轨迹从中心出发，30 s 走 1.25 周。将绝对位置平移到 FR3 home 附近。此前紧凑场景的五次时间标度、70×90 mm 轨迹与它不同。新 `paper_figure` 使用恢复的轨迹；挡块采用估计的凸棱柱，工具中心接触边界约为 `dx-dy=0.08 m`，随后转为 `dx=-0.035 m`。这两个几何数值、厚度和高度是图示估计，未获得作者 CAD。`paper_diagonal` 保留中间阶段的长斜挡板诊断场景；`compact` 保留以前默认结果。

图示折线的法向力 RMSE 约为：普通导纳 8.52 N、双向调制 4.66 N、H∞ 1.32 N。该统计受绘图降采样影响，不能称为论文原始采样 RMSE。源图 β 在 13–19 s 的折线积分均值约 0.15，与文字“接近 1”不能简单等同；密集尖峰、绘图抽样及未知抽取方式使我们不能据此恢复原始平均 β。此前将“β 平均值必须接近 1”作为数值复现门槛的判断予以纠正；论文文字描述仍保留为未核实项。

## 双向能量流的实现审计

文献 [21] DOI `10.1109/TRO.2024.3443690` 给出名义机器人、辅助 PD、补偿器、调制与能量罐。主论文采用 λ=1、不加名义重力的 PD 名义控制。它的名义惯量由机器人模型决定，不能声称其全过程严格满足与 H∞ 相同的任务空间 Λ。

原实现把 `F_measured-F_desired` 代入环境能量观测器。文献 [21] 的基本任务没有 C 的纯力控制命令，τ_ext 使用测得外力。因此新增三种明确的混合任务端口约定：

- `net`：原实现，合并外力与命令力；保留作对照。
- `physical`：观测 `(vn-v)^T J(q)^T F_measured`，命令力作为另一个供能端口记账；正式主比较使用此源公式约定。
- `physical_exact`：观测 `pdot_n^T F_n - pdot^T F`，保留虚拟/实际雅可比不同时的功率差；作为非共点映射敏感性检查。

主论文未展开 C 的混合端口细节，不能证明作者采用了其中哪一种。不能把某个扩展称作作者实现的逐行复刻。源文献名义方程使用 Jn，但调制公式写成共同 τ_ext；这里也不把其简化直接等同于七轴冗余模型中的严格功率恒等式。

在 λ=1、同坐标线性系统中，独立机械方程给出：

```
S_dot = reference_port + v*Fext - weighted_dissipation
      + (1-beta)*[(vn-v)*Fext-beta*(vn-v)*c]
      - [(1-beta)*vn+beta*v]*Fdes
```

测试独立验证该恒等式和 β=1 时实际控制器退化为辅助 PD 的性质。正式日志同时给出两个环境功率、命令力功率、Pc、β、储能、跳变代价与 μ。观测器某一项被代数消去，并不证明包含命令滤波、饱和、噪声、冗余零空间和采样保持的整个 FR3 闭环无源。

另一个实质性数值问题是：原虚拟模型 RK4 在一个控制周期内冻结整个补偿力矩。当 β=1 且使用原始高增益时，虚拟状态在约 0.02 s 内发散，实际控制器本应已经退化为不依赖虚拟状态的 PD。这是虚拟积分问题，不能解释为真实机器人不稳定。新增 `coupling_update='stages'` 在 RK4 阶段使用当前虚拟 qn/vn 计算补偿项，实际反馈、β、F/T 和实际力矩仍每 1 ms 更新一次；4/8 虚拟子步检验其收敛。默认旧配置保留，正式审计显式启用新实现。

## 接口和物理假设

[libfranka 0.21.1 头文件](https://frankarobotics.github.io/libfranka/0.21.1/lowpass__filter_8h_source.html) 给出默认命令滤波截止 100 Hz；[实现源码](https://github.com/frankarobotics/libfranka/blob/0.21.1/src/lowpass_filter.cpp) 使用

```
a = dt / (dt + 1/(2*pi*fc))
u = a*command + (1-a)*previous
```

这不改变 1000 Hz 控制/传感器时钟。`TorqueInterface` 对所有控制器共用此公式；未给力信号加反馈低通，也未默认为启用力矩变化率限制。当前 MuJoCo 滤波的是包含名义重力的总力矩，**不是完整 FCI 内置负载/重力/摩擦补偿或实机驱动模型**。

共同环境包含关节库仑摩擦和粘性阻尼、10% 正弦分布惯性误差、未建模 0.4 kg 工具、关节和 F/T 噪声。它们是已公开的仿真假设，未经过用户实机标定。共同接触参数 `solref=(.04,1), solimp=(.5,.5,.001)` 表示假设的柔顺接触；它们不是材料 SI 刚度/阻尼。接触阻尼探索中保持 `timeconst*dampratio` 不变仅保持 MuJoCo 参考刚度项；不构成物理标定。

## 证据版本

正式矩阵由 `scripts/validate_c_mechanism.py` 固定枚举，不按最好 RMSE 选择种子。它核对完整配置和运行时代码哈希才复用已有运行。`scripts/report_c_mechanism.py` 检查时钟、运行长度、有限值、过滤后命令的实际限幅，并独立复算指标。原始轨迹在 `outputs/c-mechanism`；仓库保存配置、摘要、原始轨迹哈希和选定的 1 kHz 曲线。

探索索引保留早期长斜挡板、旧轨迹、接触、摩擦、延迟等负面结果。不同场景/实现版本不能混合计算一个“总体优势”。目前 4 kHz 诊断中普通导纳优于 H∞ 的结果尤其说明：1 kHz 下原增益的采样及限幅效应不能冒充论文的完整形成机制。
